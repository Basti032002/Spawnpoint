# Spawnpoint

Erstelle und verwalte Game-Server direkt auf deinem Windows-PC – Spiel auswählen,
ein paar Optionen festlegen, fertig.

## Download

**[Neueste Version herunterladen](https://github.com/Basti032002/Spawnpoint/releases/latest)** –
dort die Datei `Spawnpoint_…_x64-setup.exe` laden und starten.

Spawnpoint sucht bei jedem Start nach Updates und installiert sie automatisch.

> Windows zeigt beim ersten Start eventuell „Der Computer wurde durch Windows geschützt“.
> Dann auf **Weitere Informationen → Trotzdem ausführen** klicken.

## Spiele

Minecraft (Java & Bedrock), Terraria, Valheim, Palworld, Satisfactory, 7 Days to Die,
ARK: Survival Ascended, Rust, Counter-Strike 2 sowie als Beta Project Zomboid,
Enshrouded, Factorio und V Rising.

Dieses Repository enthält nur die Downloads und den Spiele-Katalog (`catalog.json`).
